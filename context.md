# Contexto del Proyecto

Este archivo proporciona un resumen del contexto y propósito del proyecto para facilitar la comprensión rápida y reducir la carga informativa del README.md.

## Descripción General
Este proyecto es un dashboard financiero que permite visualizar y analizar datos financieros clave a través de una interfaz web moderna. Incluye un backend en Python (FastAPI) y un frontend en React (TypeScript + Vite).

## Objetivos
- Centralizar la visualización de KPIs financieros.
- Facilitar la toma de decisiones basada en datos.
- Proveer una arquitectura escalable y mantenible.

## Estructura Principal
- **backend/**: API REST en FastAPI, lógica de negocio y pruebas.
- **frontend/**: Aplicación React, componentes visuales, hooks y utilidades.
- **memory-bank/**: Documentación viva sobre el estado, contexto y decisiones del producto.

## Tecnologías Clave
- **Backend**: Python, FastAPI, Docker
- **Frontend**: React, TypeScript, Vite, Eslint
- **Infraestructura**: Docker Compose

## Público Objetivo
- Equipos financieros y técnicos que requieren monitoreo y análisis de datos financieros en tiempo real.
